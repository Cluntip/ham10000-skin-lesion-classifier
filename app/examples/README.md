# app/examples/

Example images shown under the demo (`gr.Examples` picks up every `.jpg` / `.png` in this folder).

Filled in Week 13, after the error analysis. Planned set: 4–6 **test-split** images, small (resize to about 300 px wide), including:

- one correct, confident prediction per common class (`nv`, `mel`, `bkl`),
- at least one **known failure case** from `worst_errors.csv` (the rubric asks the demo to show one), named e.g. `failure_mel_predicted_nv.jpg`.
